open-interceptor

A local proxy between Claude Code and your model providers. It reads the model field of every request and routes it to the right provider — translating formats when needed.

Install

curl -fsSL https://ragnito.github.io/open-interceptor/install.sh | bash

Downloads the prebuilt binary for your platform, verifies its SHA-256 checksum, and installs it to ~/.local/bin.

Supported platforms

OSArchitecturesDaemon
macOSApple Silicon, Intellaunchd
Linuxx86_64, aarch64 (static musl)systemd user service

Then

# 1. Create your config
mkdir -p ~/.config/open-interceptor
curl -fsSL https://raw.githubusercontent.com/ragnito/open-interceptor/master/config.yaml.example \
  -o ~/.config/open-interceptor/config.yaml

# 2. Start the background daemon
open-interceptor start --install
open-interceptor status

# 3. Run Claude Code through the proxy
open-interceptor claude

Inside Claude Code, switch providers with /model <name> — no reload, no wrapper scripts.

Why

  • One ANTHROPIC_BASE_URL, many providers (Anthropic, DeepSeek, OpenRouter, any OpenAI-compatible endpoint).
  • Anthropic Messages ↔ OpenAI Chat Completions translation, including streaming.
  • SSE relayed chunk by chunk — no buffering of responses.
  • Single static binary, no runtime, small memory footprint.
